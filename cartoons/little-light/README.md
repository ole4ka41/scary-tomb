# Little Light — Маленький свет

Оригинальный короткий 2D-мультфильм: ёжик помогает светлячку выбраться из лужи, затем светлячки освещают ему дорогу домой.

- Вертикальный MP4, 1080×1920, 24 кадра/с, 38 секунд.
- Все персонажи и фоны нарисованы программно; кадры, звук и оформление приложенного примера не использованы.
- Музыка: наша оригинальная синтезированная композиция `music/little-light-original.wav`.
- Хук: `EVEN TINY HEROES NEED HELP.`
- Финал: `instagram.com/ole4ka.ivanowa`.
- Шрифт: присланный пользователем Coolvetica Regular. Сам файл шрифта не включён в репозиторий.

`animate.py` — исходник сборки; использует Python, Pillow, FFmpeg и локальные пути к музыке и шрифту в подготовленной облачной среде. Для другой среды пути необходимо адаптировать. Это стилизованная программная 2D-анимация, не 3D-генерация.
