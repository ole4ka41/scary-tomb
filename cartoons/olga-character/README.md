# Рисованная героиня по мотивам фото Ольги

По следующей просьбе пользователя добавлена версия `olga-photo-to-cartoon.mp4`: сначала исходная карточка из `cards/olga-lesson-11/card.png`, затем плавный переход 0,7 секунды к анимации. Общая длительность около 14,3 секунды. Вся карточка вписана в кадр без обрезки, музыкальная дорожка непрерывна, звук нажатия синхронизирован с новой шкалой времени.

12-секундная оригинальная программная 2D-анимация, MP4 1080×1350, 24 кадра/с.

Героиня сидит за столом, встаёт, подходит к планшету и нажимает кнопку воспроизведения. На планшете запускается новая нарисованная анимация ракеты. Внешность стилизована по фото пользователя: длинные светло-каштановые волосы, светлый жакет, золотистые часы. Точное портретное сходство не заявляется; фотография не деформируется и не используется как анимированная вырезка.

Включены фрагмент ранее созданной оригинальной музыки Little Light и синтезированный звук нажатия. Все надписи на английском; финал содержит instagram.com/ole4ka.ivanowa.

Исходник `animate.py` использует Pillow, NumPy, FFmpeg, локальный файл шрифта Coolvetica и нашу музыку из подготовленной среды. Перед повторной сборкой в другой среде необходимо адаптировать абсолютные пути. Файл шрифта не распространяется в этом репозитории.
