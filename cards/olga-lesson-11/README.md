# Анимированная карточка «AI-практика с Ольгой», урок 11

14 секунд, 1200×1312, 30 кадров/с, MP4 H.264 + AAC. Пропорции исходной карточки сохранены с округлением ширины до чётного числа для видеокодека.

Использован оригинал PNG пользователя из ZIP. Текст, лицо, логотип и содержание не перерисовывались. Добавлены мягкое приближение с возвратом, золотистые световые акценты и последовательная подсветка четырёх шагов. Фоновая музыка — фрагмент нашей ранее созданной оригинальной композиции Little Light с плавным затуханием.

Сборка выполнена на Remotion из подготовленной «Коробки монтажа», через отдельную композицию `OlgaCard`, без изменения исходного кода, `reel.json` и `stil.json` коробки. Исходник композиции — `index.tsx`; PNG — `card.png`.

Для повторной сборки нужны React/Remotion из коробки и папка public с `card.png` и `music.m4a`. В текущей среде она расположена в `/workspace/outputs/ai-card/public`.
